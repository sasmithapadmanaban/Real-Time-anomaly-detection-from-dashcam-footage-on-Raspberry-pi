# Real-Time-anomaly-detection-from-dashcam-footage-on-Raspberry-pi
Real - time anomaly detection using optical flow and TensorFlow lite on Raspberry pi

Real-time anomaly detection from dashcam footage using 
Python, OpenCV and Raspberry Pi.
Features
- Real-time detection using webcam or dashcam
- Optical Flow, Background Subtraction, Frame Difference
- Live web dashboard viewable on Raspberry Pi browser
- Auto saves video clips when anomaly detected
- Alert logging with timestamps
Tech Stack
- Python 3.10
- OpenCV 4.x
- Flask (Web Dashboard)
- Raspberry Pi 32-bit OS compatible
